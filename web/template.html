Football DWH · live demo

A small data warehouse built from Premier League results. Data tampil di sini dibaca langsung dari hasil pipeline (DuckDB), bukan angka manual. Source code

Pipeline

CSV source→Data lake (partitioned)→Staging→Star schema→Marts→10 quality checks→Parquet / S3

Scheduled daily with Airflow. Quality gate: if any check fails, the pipeline stops and nothing is exported.
